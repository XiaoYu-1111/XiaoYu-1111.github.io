基于CUDA加速的高性能二维弹性波场模拟平台

发表于 2026-05-30 更新于 2026-10-07 分类于 学术研究与技术项目 阅读次数：

基于CUDA加速的高性能二维弹性波场模拟平台

摘要 (Abstract)

CMakePro_CUDA_SeisSim 是一套基于 C++17 + NVIDIA CUDA + OpenGL 4.3 + Dear ImGui / ImPlot 构建的实时二维弹性波场数值模拟与地震数据分析系统。

系统以 GPU 异构并行计算为核心，将弹性波有限差分（FDM）求解、实时波场可视化、地震数据采集、SEG-Y 数据 I/O、地震记录分析以及波场电影回放整合到统一的交互式物理仿真环境中。

通过将有限差分（FDM）算法迁移至 GPU，并深度优化显存与内存间的传输带宽，该系统在主流移动端显卡（如 RTX 4060 Laptop）上实测达到了 5.0+ GNUPs（每秒五十亿次网格点更新）的吞吐量，实现了亚秒级的万步波动方程演化。

1. 技术架构

系统采用：

状态与参数控制层 → GPU 物理计算层 → GPU 渲染与数据分析层

的模块化架构，将 UI、物理求解、数据采集和图形渲染进行解耦。

2. 数值模拟核心

2.1 八阶交错网格有限差分

物理核心基于一阶速度-应力弹性波方程。

空间离散采用 8 阶 Staggered-Grid FDM，时间方向采用二阶差分。

主要状态变量包括：

  • 质点速度 vx
  • 质点速度 vz
  • 正应力 σxx
  • 正应力 σzz
  • 剪应力 σxz

通过交错网格布置速度与应力变量，可以降低空间差分色散，并改善弹性波传播过程中的数值稳定性。

2.2 多种边界条件

系统支持三种主要边界配置。

Type 1 — Full PML

整个计算区域采用分裂场 PML 吸收边界。

Type 2 — Hybrid FDM + PML

计算区域内部采用经典非分裂场更新，仅在 PML 区域启用分裂变量。

该模式可以减少计算量和显存带宽压力。

Type 3 — Free Surface

模型顶部采用自由表面边界：

其余边界采用 PML。

该模式用于模拟自由表面条件下的弹性波传播，包括 Rayleigh 波等面波现象。

2.3 PML 流固边界稳定化

针对水层等：

的流体介质在弹性波 PML 中可能导致数值不稳定的问题，系统实现了 PML 内部介质稳定化机制。

8.2 模型裁剪与导出

  • Spatial Cropping
  • Horizontal Flip
  • PML Boundary Removal
  • 2D Resampling
  • Downsampling
  • Upsampling

例如：

可以生成用于后续处理的二维 SEG-Y 物性模型。

9. 多通道地震数据采集

系统提供主动源与被动源地震数据采集流程。

9.1 Receiver 布设

用户可以设置：

  • Receiver 数量
  • 地表布设范围
  • Receiver 深度

Receiver 在波场中以黄色倒三角标记显示。

其物理坐标同步至 GPU。

9.2 双分量采集

支持：

两个分量的同步采集。

提供两种主要模式：

被动监听。

以及：

主动激发。

主动采集时可以：

  1. 清空当前物理场；
  2. 重置时间轴；
  3. 激发震源；
  4. 持续记录 Receiver 数据；
  5. 达到录制时长后自动停止。

9.3 SEG-Y 输出

采集结果可以输出为：

对应水平与垂直分量。

Trace Header 中写入包括：

  • 野外记录号
  • 道号
  • 炮点物理坐标
  • 检波点物理坐标
  • 采样相关信息

等记录信息。

系统支持波场电影录制与回放。

数据缓存主要位于：

回放时仅将当前活动帧上传 GPU。

因此可以降低长时间波场录制对显存容量的压力。

支持：

导出的 Raw 数据可以进一步使用 Python 等工具进行后处理。
