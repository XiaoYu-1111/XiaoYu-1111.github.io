🧩 我的技术特点

01 · Domain + Engineering

不是单纯的软件开发背景，也不是只做理论研究，而是尝试连接专业问题、算法和工程实现。

02 · C++ + CUDA 是长期技术底座

AI 可以降低大量基础代码的开发成本，但 GPU、内存、并行、Kernel、性能分析、编译系统和 HPC 仍需要扎实的工程能力。因此 C++ / CUDA 是我希望长期积累的核心能力。

03 · Python 是连接 AI 的桥梁

Python 将作为连接数据、科学计算、机器学习、深度学习和自动化的重要工具，与 C++ / CUDA 形成互补。

04 · 重视可视化

我比较关注“计算结果如何被人理解和使用”，因此希望把复杂算法和计算过程转化为可交互、可视化、实时的专业工具。

🤖 AI 时代的定位

AI 对我的定位不是替代程序员，而是：

  • AI Programmer：辅助编码
  • AI Research Assistant：辅助研究
  • AI Debug Assistant：辅助调试
  • AI Testing Assistant：辅助测试
  • AI Engineering Assistant：辅助工程

Human Architecture + AI Implementation + Human Verification

🤖 AI 时代，我对编程的判断

AI 正在快速降低 API 查询、样板代码、GUI、测试代码、Debug 初筛和文档整理等工作的成本。

但 AI 并没有同时消除： 问题定义、专业领域知识、算法设计、系统架构、性能分析、工程取舍、数据质量判断和结果验证。

因此未来程序员的价值会逐渐从：

“我会不会写代码？”
↓
“我能不能定义正确的问题，并让 AI 帮我构建、验证和优化系统？”
